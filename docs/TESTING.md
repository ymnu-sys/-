# 測試說明（課堂展示原型）

## 一、自動化單元測試

```powershell
npm test
```

使用 Node 內建 `node --test`，不需要安裝套件。測試檔在 `tests/`，以記憶體儲存取代 localStorage。

| 測試檔 | 涵蓋內容 |
|---|---|
| `storage.test.js` | 公開資料與驗證特徵分開存放、重置、種子資料不含 Email／手機 |
| `auth.test.js` | 登入失敗、登出、角色檢查、登入後導回網址防止外部跳轉 |
| `items.test.js` | 白名單公開欄位、隱藏特徵搜尋不到、類別／校區／關鍵字篩選、敏感資料偵測、刊登驗證、管理員專用函式 |
| `claims.test.js` | 認領資格規則、狀態機合法／非法轉換、非管理員不能審核、補充資料、現場核對、完成後自動結案其他申請 |
| `notifications.test.js` | 依使用者篩選、未讀數、只能標記自己的通知 |

## 二、手動測試清單

測試前：`npm start`，開啟 <http://localhost:3000>，按頁尾「重置示範資料」。

示範帳號：`student_a / demo1234`（拾獲者）、`student_b / demo1234`（認領者）、`visitor / demo1234`（校外人士）、`admin / admin1234`（管理員）。
